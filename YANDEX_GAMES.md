# Сборка «ФинПути» для Яндекс Игр

## Сборка архива

```bash
npm install
npm run package:yandex
```

На выходе создаётся `finlife-yandex-game.zip`. Архив содержит статический сайт с `index.html` в корне; SDK Яндекс Игр загружается по рекомендуемому относительному пути `/sdk.js` уже на платформе.

## Что отличается в Yandex-сборке

- Live-запросы к Gemini отключены. События и новости выбираются из локальных заранее подготовленных пулов.
- SDK инициализируется через `YaGames.init()`. После готовности интерфейса отправляется `LoadingAPI.ready()`, а `GameplayAPI.start()/stop()` сообщают о начале, сворачивании и возвращении в игру.
- При потере фокуса звуковой контекст приостанавливается; системное контекстное меню в игровом окне отключено.
- Шрифты не загружаются с Google Fonts, а `public/` с ZIP-архивами сайта не копируется в Yandex-сборку.
- Сохранение пока остаётся в `localStorage`: оно переживает обновление страницы на том же устройстве, но не синхронизируется между устройствами. В этой версии нет внутриигровых покупок.

## Настройка черновика в консоли

1. Загрузите `finlife-yandex-game.zip` в черновик Яндекс Игр и проверьте игру в тестовом режиме на компьютере и мобильном устройстве.
2. На этапе проверки SDK убедитесь, что индикатор Game Ready срабатывает после появления интерфейса.
3. Реклама и покупки в этой версии отключены. В комментарии разработчика укажите: «В игре нет рекламы и внутриигровых покупок; монетизация не используется».
4. Проверьте восстановление сохранения после перезагрузки страницы и поворот экрана на мобильном устройстве.
5. Если модерация потребует межустройственные сохранения или монетизацию, их нужно отдельно подключить через Yandex Games SDK и повторно проверить сборку.

Сборка не заменяет проверку в консоли и решение модерации Яндекс Игр.

# Сборка «ФинПути» для Яндекс Игр

## Сборка архива

```bash
npm install
npm run package:yandex
```

На выходе создаётся `finlife-yandex-game.zip`. В ZIP `index.html` находится в корне; SDK Яндекс Игр подгружается по `/sdk.js` на платформе.

## Интеграция платформы

- Live-запросы к Gemini отключены. Новости и игровые события выбираются из локальных заготовленных пулов: 10 макро-выпусков по шесть тематических статей (60 уникальных карточек новостей) и 56 различных игровых событий. Случайные выпуски не повторяются подряд.
- При запуске язык считывается из `ysdk.environment.i18n.lang`; выбранная локализация устанавливается до `LoadingAPI.ready()`. Пока переведён только русский интерфейс, остальные коды языка используют русскую локализацию. В поле языков черновика указывайте только русский, пока переводы других языков не готовы.
- SDK инициализируется через `YaGames.init()`. После восстановления сохранения вызывается `LoadingAPI.ready()`, а `GameplayAPI.start()/stop()` и события `game_api_pause/game_api_resume` отмечают паузу, объявления и возврат в игру.
- Межстраничное объявление запрашивается через `ysdk.adv.showFullscreenAdv()` после закрытия годового отчёта раз в три завершённых игровых года. Во время объявления игра и звук приостанавливаются; фактический показ и частоту регулирует Яндекс.
- Прогресс загружается из Player API (`getPlayer().getData()`) и сохраняется через `setData()`. Вызовы объединяются с интервалом, чтобы не превышать лимиты SDK; перед уходом со страницы выполняется немедленная отправка ожидающего сохранения. После выбора аккаунта Яндекса игра перезапускается и перечитывает выбранное облачное сохранение. Если облако недоступно, игра продолжает использовать `localStorage`.
- Облачный снимок ограничивает аналитику последними 60 годовыми точками и 25 выпусками новостей, чтобы оставаться в пределах лимита данных SDK. Локальное сохранение сохраняет полную историю.
- Авторизация не запрашивается принудительно; игрок может начать игру как гость. Шрифты Google не загружаются, а `public/` с ZIP-архивами сайта не копируется в Yandex-сборку.

## Настройка черновика в консоли

1. Загрузите `finlife-yandex-game.zip` в черновик Яндекс Игр и проверьте игру на компьютере и мобильном устройстве.
2. В настройках черновика включите опцию использования облачных сохранений.
3. В разделе монетизации/рекламы активируйте рекламу и настройте рекламные блоки для игры. Покупки в этой версии не реализованы.
4. Проверьте в тестовом запуске восстановление прогресса после перезагрузки и на другом устройстве; пройдите три игровых года и закройте годовой отчёт, чтобы проверить точку вызова межстраничной рекламы.
5. При необходимости проверьте согласование сохранений после входа в аккаунт Яндекса и тестовое поведение при отказе от объявления.

## Комментарий разработчика для черновика

> При запуске язык автоматически считывается из `ysdk.environment.i18n.lang`; в текущей версии игры локализован русский язык. Используются межстраничные объявления, вызываемые только через SDK Яндекс Игр после закрытия годового отчёта раз в три завершённых игровых года. Прогресс сохраняется через Player API; при недоступности облака используется локальное сохранение. Авторизация не обязательна. Внутриигровые покупки не подключены. Игровые новости и события заранее подготовлены локально; интерактивные AI-запросы не отправляются. Игра является симулятором и не представляет собой финансовую или инвестиционную рекомендацию.

Сборка и автоматические проверки не заменяют проверку рекламных блоков и сохранений в тестовом запуске Яндекс Игр или решение модерации.
